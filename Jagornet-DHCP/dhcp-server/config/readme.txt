Jagornet DHCP Server configuration files
========================================

dhcpserver.xml / .yaml / .json        - default Jagornet DHCP server configuration files
dhcpserver-basic.xml / .yaml / .json  - basic example Jagornet DHCP server configuration files
dhcpserver-sample.xml / .yaml / .json - comprehensive example Jagornet DHCP server configuration files
dhcpserver-jib.json                   - default container (Jib/Docker) configuration file
dhcpserver-autocomplete.xml           - XML template linked to dhcpserver.xsd for IDE autocompletion
dhcpserver.xsd                        - Jagornet DHCP server configuration XML Schema file
log4j2.xml                            - Jagornet DHCP server Log4j2 logging configuration file
jagornet_*_keystore.p12               - sample PKCS12 keystores for HTTPS REST API and gRPC HA mTLS
jagornet_*_truststore.p12             - sample PKCS12 truststores for HTTPS REST API and gRPC HA mTLS
gen-keystores.sh                      - helper script to generate self-signed keystores/truststores
jdbc.properties                       - placeholder for JDBC database connection properties
